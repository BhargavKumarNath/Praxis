# Domain Glossary

| Term | Meaning |
| --- | --- |
| Synthetic | Generated by the Praxis simulator. Never presented as real business data. |
| Simulator | Scientific instrument producing events from known latent customer parameters. |
| Ground truth | The simulator's true latent parameters (e.g. elasticity), used to validate models. |
| Event envelope | Versioned wrapper around every event: IDs, times, trace, source, payload. |
| `event_id` | Idempotency key. Consumers dedupe on it; delivery is at-least-once. |
| Trace ID | 32-hex W3C-compatible ID following a request or event across services. |
| Correlation ID | UUID identifying one business flow end to end. |
| Causation ID | `event_id` of the event that directly caused this one. |
| Control plane | Postgres: compact mutable operational state. |
| Analytical plane | BigQuery: large analytical facts and marts. |
| Raw archive | GCS: immutable replayable source data. |
| DLQ | Dead-letter queue for messages that repeatedly fail processing. |
| PaymentGateway | Interface for all payment operations; Stripe and Synthetic implementations. |
| Elasticity | Causal response of demand to price. Not a predictive regression coefficient. |
| Optimiser | Constrained decision engine that chooses prices. |
| Guardrail | Deterministic rule that can reject or freeze a decision regardless of the model. |
| Shadow / recommend / execute | Pricing modes: compute only, propose, or apply. Start in shadow. |
| Champion / challenger | Production model versus candidate under evaluation. |
| Drift | Change in features, predictions, calibration or outcomes. Evidence, not proof. |
| Dunning | Process of recovering failed payments. |
| CLV | Customer lifetime value, used as a long-horizon guardrail. |
| SLO | Measurable service objective (latency, freshness, availability). |
| AI Revenue Operator | LLM agent that observes and orchestrates via typed, audited tools. |
